# ActGiving - Sistem Informasi Donasi & Volunteering

## 📖 Deskripsi Proyek
**ActGiving** adalah sebuah platform ekosistem terpadu yang menghubungkan donatur, inisiator kegiatan sosial, dan calon relawan di lapangan. Sistem ini dirancang untuk mengatasi hambatan partisipasi aksi kemanusiaan dengan memangkas proses registrasi yang rumit saat berdonasi, memusatkan manajemen kampanye sosial, dan memberikan transparansi penuh melalui Laporan Pertanggungjawaban (LPJ) digital. 

Melalui ActGiving, sebuah inisiatif sosial dapat menghimpun dukungan finansial sekaligus merekrut relawan fisik secara simultan dalam satu kampanye terpadu.

## ✨ Fitur Utama
- **Guest Donation (Donasi Cepat):** Memungkinkan donatur publik untuk berdonasi secara instan tanpa kewajiban mendaftar atau login akun.
- **Kampanye Multi-Opsi:** Inisiator dapat membuat kampanye dengan 3 mode:
  1. Hanya Butuh Dana
  2. Hanya Butuh Relawan
  3. Butuh Keduanya (Dana & Relawan)
- **Rekrutmen Relawan Berbasis Lokasi:** Memudahkan calon relawan menemukan dan melamar kegiatan sosial terdekat dari domisili mereka.
- **Dasbor Kurasi Relawan:** Inisiator dapat menyeleksi (terima/tolak) pelamar relawan langsung dari dalam sistem.
- **Transparansi LPJ Digital:** Publikasi laporan penyaluran dana dan dokumentasi lapangan yang dapat diakses langsung oleh publik di halaman kampanye.

## 🛠️ Teknologi yang Digunakan
Berdasarkan arsitektur 3-Tier yang dirancang, proyek ini dikembangkan menggunakan:
- **Presentation Tier (Frontend):** React.js / Next.js, Tailwind CSS
- **Business Logic Tier (Backend):** Laravel (PHP) / Node.js (Express)
- **Data Tier (Database):** PostgreSQL / MySQL
